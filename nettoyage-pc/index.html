Analyse et suppression des virus, malwares et adwares

⬇ Télécharger RD IT Nettoyage

Windows 10 et 11 · un seul fichier · aucune installation

Lancer le nettoyage

  1. Si Chrome ou Edge signale le fichier, choisissez Conserver.
  2. Double-cliquez sur RD-IT-Nettoyage.cmd dans vos téléchargements.
  3. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires puis Exécuter quand même.
  4. Acceptez la demande d'autorisation administrateur (Oui).

Ce que fait l'outil

  • Point de restauration avant toute intervention
  • Analyse Microsoft Defender à jour (rapide ou complète)
  • Microsoft Safety Scanner en second avis
  • AdwCleaner : adwares, barres d'outils, pirates de navigateur
  • Vérifications : proxy, fichier hosts, extensions imposées, tâches suspectes
  • Nettoyage des fichiers temporaires et rapport pour le client
