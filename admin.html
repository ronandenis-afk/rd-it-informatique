Connexion

La console enregistre tout dans tes dépôts GitHub. Il lui faut un jeton d'accès GitHub, que tu crées une seule fois :

  1. Ouvre github.com → Fine-grained token.
  2. Nom : « Console RD IT ». Expiration : au choix (1 an par exemple).
  3. Repository access → Only select repositories → choisis rd-it-informatique et rd-it-gestion.
  4. Permissions → Contents : Read and write.
  5. Clique sur Generate token, copie-le et colle-le ci-dessous.

Suivi de l'activité

Clients, interventions et réparations. Données privées, enregistrées dans ton dépôt privé rd-it-gestion.

Créer ton dépôt privé

Le dépôt privé rd-it-gestion n'existe pas encore (ou ton jeton n'y a pas accès). Il sert à stocker tes données clients, invisibles du public.

  1. Ouvre github.com/new, nom rd-it-gestion, choisis Private, coche Add a README file, puis Create repository.
  2. Ajoute ce dépôt à ton jeton (Settings → Developer settings → Fine-grained tokens → ton jeton → Repository access).
  3. Reviens ici et clique sur « Réessayer ».

Statistiques des visites

Nombre de visiteurs, pages vues, appareils (ordinateur, téléphone, tablette) et provenance (Google, Facebook, lien direct…). Mesure sans cookies avec GoatCounter.

Brancher les statistiques (une seule fois)

  1. Crée un compte gratuit sur goatcounter.com/signup avec le code rditinformatique (le site compte déjà les visites sous ce code).
  2. Dans GoatCounter : Settings → Sites that can embed GoatCounter : ajoute rd-it-informatique.com, puis Save.
  3. Toujours dans Settings → Dashboard viewable by : choisis logged in users or with secret token, enregistre, puis copie le lien affiché (il contient access-token=).
  4. Colle ce lien ci-dessous et clique sur « Afficher ».
