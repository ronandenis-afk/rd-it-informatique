RD IT Diagnostic PC

Diagnostic complet d'un ordinateur Windows

⬇ Télécharger RD IT Diagnostic

Windows 10 et 11 · un seul fichier · aucune installation

Lancer le diagnostic

  1. Si Chrome ou Edge signale le fichier, choisissez Conserver.
  2. Double-cliquez sur RD-IT-Diagnostic.cmd dans vos téléchargements.
  3. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires puis Exécuter quand même.
  4. Acceptez la demande d'autorisation administrateur (Oui).

Ce qui est testé

  • Système : Windows, activation, BIOS, TPM, Secure Boot
  • Processeur : score et test de charge
  • Mémoire RAM : test d'écriture et de relecture
  • Disques : santé SMART, usure, température, vitesse, erreurs
  • Batterie, carte graphique, réseau et débit Internet
  • Pilotes, antivirus, mises à jour, écrans bleus

Un rapport est créé à la fin dans le dossier « Rapports RD IT » du Bureau.
